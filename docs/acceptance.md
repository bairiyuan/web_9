# 验收演示顺序

1. 在用户端注册普通用户，登录后点击开始练习，完成所有题目并提交，查看分数与逐题反馈。
2. 普通账号尝试登录管理端，应被拒绝。
3. 使用管理员登录管理端，在用户管理中查询刚注册账号；新增普通用户和管理员；删除测试用户。
4. 重置普通账号密码为123456，原登录失效，新密码可以登录。
5. 在题库管理中新增题目，修改内容/四个选项/正确答案，按关键词查询后删除。
6. 初始题库有12题，每页10条，演示上一页、下一页；用户分页可新增足够测试用户演示。
7. 展示Nginx的Quiz配置、systemd服务、独立MySQL数据库，以及docs/server-changes.md。

JWT有效期两小时；后端接口也检查当前数据库角色。答题接口不返回正确答案，提交后服务端计算结果。成绩只即时展示，未实现历史成绩持久化（验收书未要求）。
